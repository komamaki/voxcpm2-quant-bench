# 任务说明 · VoxCPM2 在 8 GB 显存上与 4B LLM 共存

> 本文件是任务包的**正式定义**：目标、输入、输出、判定标准、以及为什么它不容易。
> 配套实现见 `bench/`，自动评分见 `score/`。

---

## 1. 目标

在一张 **8188 MiB** 的 GPU 上，让下面两者**同时可用**：

1. **常驻 LLM** —— 一个 4B 级 Qwen 模型，由 `llama-server` 常驻（约 3.3 GB），端口 8899。
2. **VoxCPM2 TTS** —— 语音合成，全精度下约 4.5 GB。

必须**同时**满足：

- 全流程峰值显存 **≤ 8188 MiB**（不 OOM、不靠 swap 硬撑）
- 共存状态下 TTS **RTF ≤ 1.0**（实时）
- 音质相对 bf16 基线的漂移在代理指标阈值内

在满足以上三条的前提下，**最大化显存余量**。

---

## 2. 为什么它不容易

| 障碍 | 说明 |
|---|---|
| 显存贴顶 | bf16 下两者相加 = 7814 MiB，占 95.4%，余量不足以支撑长时间运行 |
| 速度劣化 | 共存时 RTF 从 1.0 劣化到 **14.4** —— 生成 1 秒音频要 14 秒 |
| 量化不是免费的 | 4-bit 量化会引入量化噪声；对 TTS 而言这直接表现为音色漂移、金属感、爆音 |
| 模块异质性 | VoxCPM2 不是单一 Transformer：LM 主干、AudioVAE、扩散解码器对量化的敏感度完全不同 |
| 峰值 vs 稳态 | "量化瞬间"的显存峰值可能高于量化后的稳态，共存时正是这一刻最容易 OOM |

**关键认知**：显存和延迟是两个独立的约束，不能只优化一个。
把模型压进显存却让 RTF 涨 14 倍，等于没解决。

## 3. 输入

| 输入 | 说明 |
|---|---|
| 硬件 | 单张 8 GB 级 GPU（本基准：RTX 4060 Laptop，8188 MiB） |
| 模型 A | VoxCPM2 权重（ModelScope `OpenBMB/VoxCPM2`，约 4.7 GB） |
| 模型 B | 4B 级 Qwen，经 `llama-server` 常驻（约 3.3 GB） |

## 4. 输出（提交物）

提交者需要提供：

1. **`results/results.json`** —— 至少包含自己配置下的共存实测：
   ```json
   { "coexist": { "peak_vram_mib": <int>, "rtf": <float> } }
   ```
   （其余字段可保留，见仓库内文件结构）

2. **`results/samples/` 下的 wav 对** —— 与 bf16 基线**同 seed** 的候选音频。
   推荐直接跑 `bench/b09_seed_matched_quality.py` 生成，它会写 `run_meta.json` 记录 seed。

3. **一段方法说明** —— 量化了哪些模块、为什么、代价是什么（可写在 PR 描述或 `docs/`）。

## 5. 判定标准

全部由 `score/score.py` 自动完成，**无需人工听音**：

### ① 硬门槛

| 指标 | 上限 | 来源 |
|---|---|---|
| 共存峰值显存 | 8188 MiB | `results.coexist.peak_vram_mib` |
| 共存 RTF | 1.0 | `results.coexist.rtf` |

### ② 音质代理（相对 bf16 基线）

| 指标 | 阈值 | 权重 |
|---|---|---|
| log-mel 谱距离 LSD | ≤ 3.0 dB | 0.50 |
| 高频能量占比相对变化 | ≤ 30% | 0.25 |
| 谱通量 p95 相对变化 | ≤ 50% | 0.25 |

加权得分 **≥ 0.7** 视为音质通过。

### ③ 最终结论

- 硬门槛 **且** 音质都通过 → `PASS`
- 硬门槛通过但样本 seed 不一致（音质不可评） → `FAIL(音质未验证)`
- 否则 → `FAIL`

## 6. 测量口径（重要）

**显存必须用 `nvidia-smi` 测真实总占用，不能用 `torch.cuda.memory_allocated()` 估算。**
后者只统计当前进程的 PyTorch 分配，看不到 `llama-server` 这个**独立进程**占的 3.3 GB ——
这正是本任务的核心陷阱（见 `bench/t1d_coexist.py` 的设计注释）。

**音质对比必须同 seed。** 否则谱距离混入随机采样差异，指标无意义。
注意：本机安装的 `voxcpm==2.0.3` 的 `generate()` **没有** `seed` 参数，
需用 `torch.manual_seed()` + `torch.cuda.manual_seed_all()` 在外部播种，
并关闭 `retry_badcase`（其重试循环会额外消耗 RNG）。
